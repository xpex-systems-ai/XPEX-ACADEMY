# Módulo 3 — Prompt Engineering

## Objetivo
Aprender a transformar intenção vaga em uma especificação que a IA consegue executar e que você consegue avaliar.

## Estrutura de um bom prompt
Um prompt profissional normalmente deixa claro:

1. **Objetivo:** o resultado desejado.
2. **Contexto:** informações necessárias para executar.
3. **Restrições:** limites, formato, tom, público e coisas proibidas.
4. **Critério de qualidade:** como saber se ficou bom.
5. **Saída:** estrutura esperada.

Exemplo de padrão:

```text
Objetivo: resumir esta reunião para a equipe.
Contexto: [notas].
Restrições: não invente decisões; destaque dúvidas abertas.
Saída: decisões, responsáveis, prazos e riscos.
```

## Iteração
Prompt Engineering não é encontrar uma frase mágica. É um ciclo:

**pedir → observar → identificar falha → ajustar contexto/restrição → testar novamente.**

## Prática
Pegue o prompt “crie um plano de estudos de IA”. Execute uma vez. Depois reescreva informando nível atual, horas disponíveis por semana, objetivo profissional, prazo e tipo de projeto final. Compare os resultados.

## Exercício
Crie um prompt reutilizável para revisar uma resposta sua. Ele deve pedir que a IA identifique: fatos sem evidência, ambiguidades, riscos, lacunas e uma versão melhorada.

## Regra de ouro
Quanto maior o impacto da resposta, mais explícitos devem ser os critérios e a verificação humana.
