# Boas-vindas — Inteligência Artificial do Básico ao Avançado

## Bem-vindo à formação oficial XPeX Academy

Este curso foi organizado para transformar conhecimento em prática. Você não precisa dominar programação para começar; o objetivo é avançar dos fundamentos até projetos demonstráveis com IA.

## Como estudar

Use cada módulo em quatro etapas:

1. **Aprenda** — assista à vídeo-aula e leia o material principal.
2. **Pratique** — execute o exercício proposto.
3. **Converse com o GX** — use o mentor para revisar conceitos, comparar alternativas e receber orientação.
4. **Comprove** — registre uma evidência: resposta, checklist, arquitetura, prompt, fluxo, print ou projeto.

## Como usar o GX

O GX deve complementar o curso, não substituir sua análise. Pergunte sobre o conteúdo do módulo, peça exemplos, solicite revisão de um exercício e compare a resposta com o material da aula.

Quando uma resposta envolver fatos, decisões importantes ou dados externos, valide antes de usar.

## Critério de progresso

O progresso deve refletir atividades realmente concluídas. Checkpoints e projeto final existem para verificar compreensão e aplicação.

## Projeto final

Ao final você apresentará uma solução de IA pequena, real, compreensível e verificável. O projeto pode ser um assistente, RAG, automação, agente ou outra solução compatível com o curso.
