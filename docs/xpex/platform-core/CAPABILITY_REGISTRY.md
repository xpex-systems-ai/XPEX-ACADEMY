# Platform Core Capability Registry

## Modelo de classificação

| Status | Critério |
|---|---|
| production_ready | Capacidade funcional, usada e com implementação clara. |
| operational | Funcional, mas dependente de configuração ou infraestrutura externa. |
| partial | Cobre parte do ciclo ou mistura responsabilidades. |
| experimental | Integração opcional, protótipo ou uso limitado. |
| documented_only | Apenas documentação sem código ativo equivalente. |
| missing | Sem evidência funcional suficiente. |

## Divergências e inferências

- **Inferência:** `UserGroup` is Platform Core as a generic access grouping primitive, while cohort pedagogy remains Learning Core.
- **Inferência:** webhooks are classified as partial because data models/routers exist, but delivery runtime and retry guarantees need a focused follow-up.
- **Inferência:** audit is partial because analytics and delivery logs exist, but a complete immutable audit trail is not evidenced in the inspected core paths.
