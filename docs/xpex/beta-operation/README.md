# Operação Beta — fonte de verdade operacional

Este diretório governa a fase atual da XpeX Academy. Em caso de dúvida sobre prioridade ou sequência de execução, o [Mission Ledger](MISSION_LEDGER.md) é a fonte operacional vigente; o Trinity Flow permanece como registro do método e do histórico técnico.

## Norte da operação

- **Meta:** validar a primeira turma oficial com 10 alunos fundadores; isso é uma meta, não uma declaração de matrículas existentes.
- **Hub inicial:** Polo Kelle Digital Lab.
- **Princípio:** Pessoas primeiro. Plataforma depois.
- **Regra:** toda decisão deve responder se ajuda um aluno a aprender melhor.
- **Lema:** Aprenda. Automatize. Construa o Futuro.
- **Missão atual:** XPEX-BETA-002 está em revisão; sua integração documental não significa que turma, calendário ou projeto foram executados.
- **Próxima missão após a integração da XPEX-BETA-002:** `XPEX-BETA-003`.

## Limites

A rota inicial usa GitHub e Vercel. Artefatos e infraestrutura de staging existentes continuam preservados. Novas expansões em Google Cloud estão pausadas, não abandonadas, até haver uso real ou necessidade comprovada. Esta governança não executa deploy, não cria recurso cloud e não cria dados de alunos.
