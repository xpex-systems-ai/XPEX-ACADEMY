# Inventário de recursos de staging — primeiro deploy real

Todos os itens estão **a confirmar no GCP**. Os comandos abaixo são somente leitura e não criam, alteram, habilitam APIs nem mudam tráfego.

Status permitido: `NÃO VERIFICADO`, `EXISTENTE`, `AUSENTE`, `BLOQUEADO`, `NÃO APLICÁVEL`.

| Recurso | Nome esperado | Finalidade | Obrigatório? | Comando somente leitura para verificar existência | Resultado esperado | Responsável pela criação | Custo potencial | Status |
|---|---|---|---|---|---|---|---|---|
| Projeto GCP | `$GCP_PROJECT_ID` | Isolar staging | Obrigatório | `gcloud projects describe "$GCP_PROJECT_ID" --format='value(projectId)'` | Retorna o projeto informado | Operador GCP | Pode habilitar custos em serviços | NÃO VERIFICADO |
| Billing | Conta vinculada ao projeto | Permitir serviços pagos | Obrigatório | `gcloud billing projects describe "$GCP_PROJECT_ID" --format='value(billingEnabled)'` | `true` | Owner/Billing Admin | Custos contínuos após uso | NÃO VERIFICADO |
| APIs habilitadas | Run, Build, Artifact, Secret, SQL, Storage, Redis, VPC Access | Pré-requisito de build/deploy | Obrigatório | `gcloud services list --project "$GCP_PROJECT_ID" --enabled --format='value(config.name)'` | APIs obrigatórias listadas | Service Usage Admin | Algumas APIs habilitam serviços faturáveis | NÃO VERIFICADO |
| Artifact Registry | `$ARTIFACT_REPOSITORY` | Armazenar imagem | Obrigatório | `gcloud artifacts repositories describe "$ARTIFACT_REPOSITORY" --project "$GCP_PROJECT_ID" --location "$GCP_REGION" --format='value(name)'` | Repositório existe | Infra/DevOps | Storage e tráfego | NÃO VERIFICADO |
| Cloud Build | Projeto `$GCP_PROJECT_ID` | Build de imagem | Obrigatório | `gcloud builds list --project "$GCP_PROJECT_ID" --limit=1 --format='value(id)'` | Consulta autorizada | Infra/DevOps | Minutos de build | NÃO VERIFICADO |

| Redis | `$REDIS_INSTANCE` | Cache/fila | Obrigatório se app exigir | `gcloud redis instances describe "$REDIS_INSTANCE" --project "$GCP_PROJECT_ID" --region "$GCP_REGION" --format='value(name)'` | Instância existe | Infra | Custo contínuo | NÃO VERIFICADO |
