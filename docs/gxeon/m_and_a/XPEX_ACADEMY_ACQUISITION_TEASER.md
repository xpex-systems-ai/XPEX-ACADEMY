## 2. Platform Overview

XPeX Academy is an enterprise-grade, turn-key educational operating system engineered specifically for the AI era. Unlike traditional LMS platforms (Moodle, Teachable, WordPress), XPeX features an integrated AI copilot (**GX Tutor**), an AI-accelerated **Course Studio**, real-time multi-user collaboration, and multi-tenant organizational hierarchy for regional hubs (Polos) and corporate academies.

### Core Capabilities:
1. **Interactive AI Tutor (GX):** Native LLM integration with adaptive pedagogical mentoring, context-aware student guidance, and automated assessment.
2. **AI Course Studio:** Automated generation and structuring of curricula, modules, and audiovisual lesson pipelines.
3. **Multi-Tenant Architecture:** Built-in support for multiple independent organizations, branch campuses, and enterprise clients under isolated domains and configurations.
4. **Real-Time Collaboration:** Powered by WebSockets and Hocuspocus for collaborative student interactions and live shared workspaces.
5. **High-Performance Infrastructure:** Dockerized microservices stack deployed across Google Cloud / Firebase Hosting edge and scalable application runtimes.
