# Layout

| Viewport | Intent |
| --- | --- |
| Mobile (< 48rem) | One primary action, drawer/bottom navigation, single-column learning flow |
| Tablet (≥ 48rem) | Two-column summaries, touch-first controls, collapsible navigation |
| Desktop (≥ 64rem) | Persistent navigation and contextual secondary panels |
| Wide (≥ 90rem) | Constrained content; add context rather than stretching lines |

The shared shell uses skip navigation and a mobile drawer. Student pages order action → progress → next step → content → exploration. Polo and admin tables collapse to purposeful cards or horizontal regions rather than shrinking columns. Course Player reserves the viewport for lesson content and next/previous actions; Course Studio keeps course location, current edit target, completion gaps, and publish action visible.
